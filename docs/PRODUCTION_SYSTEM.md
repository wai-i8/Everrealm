# 生產系統 · PRODUCTION_SYSTEM

## 設計北極星

本系統以《幸福 Online／STRUGARDEN》的生產玩法為主要參考，但按《永恆國度 · Everrealm》單人流程、現有地圖、物品欄與 Lv.40 角色上限作適度簡化。

核心體驗：

> 採集原料 → 學習處方 → 培養生產技能／生產精靈 → 合成 → 取得更高品質物品 → 用更高階材料挑戰新處方。

生產係一條獨立於戰鬥職業嘅長期成長線，唔應該變成「撳一下就免費出裝備」，亦唔應該要求玩家長時間掛機等候。

---

## 原作已核實規則

以下屬《幸福 Online／STRUGARDEN》可由現存攻略／Wiki 支持嘅核心概念：

- 生產不受戰鬥職業限制。
- 生產分成兩大類：
  - **採取系**：收穫、採掘、伐採、釣魚。
  - **合成系**：調理、彫金鍛冶、木工大工、紡績裁縫、皮革加工、鍊金術。
- 合成必須先學習對應 **處方／Recipe**。
- 處方本身有生產等級要求；生產等級不足時不能製作高階物品。
- 處方可由商店、任務、世界／Boss 掉落等途徑取得；高階及稀有處方可以係探索目標。
- 原作有 **生產精靈／使役精靈**；`KNACK` 生產介面會顯示親密度。
- 重複生產會提升生產相關成長，並逐步開放更多處方。
- 部分處方會指定使用某種使役精靈。
- 生產成功／失敗會受生產等級、親密度等因素影響；低熟練玩家強行製作高難度處方會有較高材料損失風險。
- 採取會喺資源據點或城鎮／農園等採集點進行；採取熟練提升後，尋找／鎖定資源會更快。
- 原作存在生產裝備品質差異，玩家資料可見 `N`、`+1`、`+2`、`S` 等級。
- 原作後期戰鬥／生產等級上限曾提升至 Lv.75。
- 原作後期有專用生產教學，新手完成後可學到調理處方。

### 原作資料未能可靠核實的部分

現存可存取資料未足以可靠還原：

- 精確成功率公式。
- 親密度每次增加多少。
- 所有處方完整名單及等級。
- `N / +1 / +2 / S` 每級精確機率。
- 每種使役精靈同所有處方嘅完整對應表。

以上部分 **禁止聲稱係原作公式**；本文件以下數值屬本作採用／改編，全部做成 data-driven，方便之後再調整。

# 本作採用／改編

## 1. 生產分類

### 採取系

| ID | 中文 | 用途 | 主要工具 |
|---|---|---|---|
| `harvest` | 收穫 | 藥草、農作物、棉花、花材 | 鐮刀 |
| `mining` | 採掘 | 礦石、水晶、煤、稀有礦物 | 十字鎬 |
| `logging` | 伐採 | 木材、樹脂、特殊木料 | 斧 |
| `fishing` | 釣魚 | 魚類、水產、少量特殊素材／處方 | 釣竿 |

### 合成系

| ID | 中文 | 主要產物 |
|---|---|---|
| `cooking` | 調理 | 回復食品、戰前／短期 buff 食品 |
| `smithing` | 彫金鍛冶 | 金屬材料、刀劍、拳套、金屬裝備、部分飾物 |
| `woodwork` | 木工大工 | 木材加工、木製武器、盾、工具零件 |
| `tailoring` | 紡績裁縫 | 線、布、衣服、布甲 |

| `alchemy` | 鍊金術 | 藥品、特殊素材、魔法加工品 |

所有角色均可學習及提升全部十種生產技能，**戰士／格鬥士身份不限制生產種類**。

## 2. 解鎖流程

### 生產教學

- 玩家完成初期探索／公會入門 milestone 並可以自由進出主城後，可接受一次 **生產教學**。
- 教學 NPC 放喺主城內，位置以接近 `銀火裝備店` 或其內部為優先，避免新增無必要大型建築。
- 教學只需完成一次。
- 完成後：
  - 解鎖左側 `生產` 功能。
  - 取得基礎鐮刀、十字鎬、斧、釣竿。
  - 學會第一個調理處方：`月之藥草 I`。
  - 解鎖基礎生產精靈介面。
- 生產教學不可因重讀舊 save 而重複派發唯一獎勵。

### `生產` 左側功能

- 左側新增 `生產`。
- 開啟只係查看生產資料，**唔會自動移動玩家去任何工房或資源點**。
- 介面包含：
  - 採取
  - 合成
  - 處方圖鑑
  - 生產精靈
- 介面沿用現有網站式 modal 契約：
  - 右上 `×`
  - 點擊背景可關閉
  - 不加入跨頁無關功能

## 3. 生產技能等級

每一種生產技能有獨立：

```text
level
exp
```

例如：

```text
harvestLevel
miningLevel
cookingLevel
smithingLevel
```

### 等級上限

本作第一階段：

```text
Lv.1 – Lv.40
```

理由：

- 配合目前角色 Lv.40 上限。
- 減少一次建立 75 級內容造成嘅空洞 grind。
- 資料結構 **不得 hard-code 40**；日後可按內容量擴至原作曾使用嘅 Lv.75。

### 升級

成功採取／合成會得到生產 EXP。

EXP 原則：

- 製作接近自己生產等級嘅物品 → 正常 EXP。
- 製作明顯低級物品 → EXP 遞減。
- 高於自己等級嘅處方 → 不可開始製作。
- 失敗合成 → 只得到成功時 `25%` 嘅生產 EXP。

初版等級需求使用：

```text
requiredExp(level) = 20 + level * 12
```

每個生產技能獨立累積。

## 4. 採取玩法

### 資源點

資源點係正式世界物件，不使用純文字列表代替。

第一階段可放置：

- 主城／農園附近：
  - 月見草
  - 基礎食材
  - 棉花
- 野外：
  - 木材
  - 藥草
  - 基礎礦石
  - 河／水邊釣魚點
- 沉燈坑道：
  - 鐵礦
  - 稀有礦
  - 水晶
  - 高階鍊金素材

資源點資料必須 data-driven：

```js
{
  id,
  type,
  mapId,
  x,
  y,
  requiredLevel,
  toolType,
  drops,
  respawnTime
}
```

### 操作

1. 玩家點擊資源點。
2. 自動尋路去互動距離。
3. 如冇裝備／持有正確工具，顯示需要工具。
4. 到達後開始「鎖定／採取」。
5. 完成後產生材料、EXP。
6. 資源點暫時枯竭，再按 `respawnTime` 回復。

### 鎖定時間

保留原作「熟練後鎖定更快」概念，但取消過長掛機等待。

初版：

```text
lockTime = clamp(
  baseLockTime - (skillLevel - requiredLevel) * 0.04,
  0.8,
  baseLockTime
)
```

建議：

```text
baseLockTime = 2.5 秒
最低 = 0.8 秒
```

釣魚可使用較長 base：

```text
3.5 秒
```

### 採取掉落

每個資源點可有：

```js
drops: [
  { itemId, weight, min, max, minSkillLevel }
]
```

高生產等級可以：

- 提高稀有材料出現率。
- 提高一次採取數量。
- 縮短鎖定時間。

但 **不得令低階材料完全消失**，避免玩家升高級後反而無法取得舊配方材料。

## 5. 生產工具

採取必須有相應工具：

- 鐮刀
- 十字鎬
- 斧
- 釣竿

初版唔加入複雜耐久系統，以免生產系統變成維修工具模擬。

工具分級：

```text
破舊 → 普通 → 精良
```

效果只影響：

- 鎖定速度
- 採取數量小幅 bonus

工具 **不得直接提高稀有掉落至失衡程度**。

工具升級可由：

- 商店購買
- 木工／鍛冶製作
- 任務獎勵

## 6. 處方／Recipe

所有合成物品必須有正式 recipe data。

```js
{
  id,
  name,
  category,
  requiredLevel,
  requiredSpirit,
  station,
  ingredients,
  output,
  outputQty,
  baseSuccessRate,
  qualityEnabled,
  source
}
```

### 處方取得

保留原作多來源方式：

- 生產教學
- NPC 商店
- 公會委託／探索 milestone
- 寶箱
- 怪物／Boss
- 沉燈坑道探索
- 稀有世界事件（將來）

### 處方學習

- 處方以物品形式進入背包。
- 點擊後顯示：
  - 名稱
  - 生產分類
  - 所需生產 Lv
  - 所需材料
  - 所需生產精靈
  - 產物
- 玩家確認「學習」後永久登錄處方圖鑑。
- 已學處方重複取得時，不可以再次學習；可轉為可出售／其他用途嘅物品。
- 處方 **唔係一次性製作券**；學習後可以重複製作。

### 處方顯示

圖鑑分：

```text
已學會
未取得
等級不足
材料不足
可製作
```

未取得稀有處方可只顯示：

```text
？？？
```

避免直接洩露所有隱藏內容。

## 8. 生產精靈

### 原作概念

生產同「使役精靈」有直接關係；部分處方會指定精靈，`KNACK` 亦會顯示親密度。

原作資料可見以下生產精靈名稱：

- Salamander
- Undine
- Gnome
- Sylph
- Pufuri
- Dryad
- Will-o'-Wisp
- Shade

本作保留呢種特色，但 **唔將佢同戰鬥寵物混為一談**。

### 本作資料

每隻生產精靈至少保存：

```js
{
  id,
  name,
  unlocked,
  intimacy
}
```

親密度：

```text
0 – 100
```

### 解鎖

第一階段全部生產精靈由生產教學系統登錄，但親密度由 `0` 開始。

理由：

- 避免未有完整多國／資源據點內容時，玩家因缺一隻精靈而完全卡住生產。
- 將來如果增加精靈取得任務，可以再將部分精靈改為任務解鎖。

### 使用

每張處方可以：

```text
requiredSpirit = null
```

或者指定一隻精靈。

如果處方指定精靈：

- 必須已解鎖。
- 製作 UI 顯示精靈名及親密度。
- 親密度會影響成功率同品質。

### 親密度增加

成功完成一張需要該精靈嘅處方：

```text
+1 intimacy
```

首次成功製作某處方：

```text
額外 +1
```

每日／時間衰減：**無**。

避免迫玩家做維護式登入。

## 9. 合成成功／失敗

原作有失敗及爆材料風險，但精確公式未能可靠還原。

本作初版：

```text
successRate =
  baseSuccessRate
  + (productionLevel - recipe.requiredLevel) * 2
  + floor(spiritIntimacy / 10)
```

最後：

```text
25% ≤ successRate ≤ 98%
```

預設普通處方：

```text
baseSuccessRate = 75%
```

### 例子

Recipe Lv.10：

玩家：

```text
生產 Lv.10
精靈親密度 0
```

成功率：

```text
75%
```

玩家：

```text
生產 Lv.15
精靈親密度 50
```

成功率：

```text
75 + 10 + 5 = 90%
```

### 失敗處理

普通失敗：

- 不產生成品。
- 消耗所需材料。
- 獲得正常成功時 `25%` 生產 EXP。
- 精靈親密度不增加。

以下物品可標：

```text
protectedOnFailure: true
```

例如唯一任務物品，失敗時不得消失。

UI 必須喺玩家按製作前清楚顯示成功率。

## 10. 生產品質

只對：

- 武器
- 防具
- 部分飾物

使用品質系統。

品質：

```text
N
+1
+2
S
```

### 初始品質機率

成功後再 Roll：

| 品質 | 初始機率 |
|---|---:|
| N | 84% |
| +1 | 12% |
| +2 | 3.5% |
| S | 0.5% |

### 熟練加成

計算：

```text
qualityBoost =
  floor(max(0, productionLevel - recipe.requiredLevel) / 5)
  + floor(spiritIntimacy / 20)
```

```text
qualityBoost 最大 = 5
```

每 1 點 `qualityBoost`：

```text
N   -1.5%
+1  +1.0%
+2  +0.4%
S   +0.1%
```

所以 S 仍然係稀有品，唔會因刷高等級變成必出。

### 裝備數值

對該件裝備原始 production stats：

| 品質 | 數值倍率 |
|---|---:|
| N | 1.00× |
| +1 | 1.05× |
| +2 | 1.10× |
| S | 1.18× |

只放大該裝備原本有嘅數值。

例如一件只加防禦嘅裝備，不可因為 S 級突然新增攻擊或暴擊。

## 11. 製作流程

玩家企近正確工作台：

1. 開啟 `生產`。
2. 選合成分類。
3. 選已學處方。
4. 顯示：
   - 產物
   - 所需材料
   - 現有／需要數量
   - 生產 Lv
   - Recipe Lv
   - 生產精靈
   - 精靈親密度
   - 成功率
   - 是否有品質 Roll
5. 材料不足時「製作」disabled。
6. 按製作。
7. 播放短生產動畫／progress。
8. 結算成功／失敗。
9. 即時更新：
   - 背包
   - 生產 EXP
   - 生產 Lv
   - 精靈親密度
   - 處方首次製作狀態
10. 顯示結果。

單次 progress：

```text
約 1.0 – 2.0 秒
```

唔重現原作過長等待時間。

### 批量製作

已成功製作過同一處方至少一次後，可選：

```text
1 / 5 / 10 / MAX
```

每件獨立 Roll 成功率及品質。

批量製作期間不得鎖死 UI；可取消未開始嘅剩餘批次。

## 13. 經濟與平衡

生產必須有用途，但唔可以令商店及戰鬥掉落完全失去價值。

### 商店

- 商店繼續提供普通基礎裝備。
- 生產優勢：
  - 較高品質
  - 特定 recipe-only 裝備
  - 消耗品
  - 部分工具
- 玩家唔練生產仍然可以完成公會委託同探索 progression。

### 稀有材料

稀有材料主要來自：

- 高階資源點
- Boss
- 寶箱
- 公會委託
- 坑道深層

不可將所有高階 recipe 都變成單純反覆採集低級材料。

### 防止無限刷錢

NPC 收購生產品價格要低於：

```text
材料合理總價 + 玩家大量製作收益
```

避免「商店買材料 → 生產 → 賣 NPC」形成無限套利。

## 14. 與寵物系統的接口

《幸福 Online》資料亦有提及寵物可以成為生產幫手。

本作暫時只預留：

```js
productionHelperId: null
```

但 **PRODUCTION_SYSTEM 不自行定義寵物加成**。

將來建立：

```text
docs/PET_SYSTEM.md
```

之後先由寵物文件決定：

- 邊類寵物可協助生產。
- 加成功率、速度、材料數量定品質。
- 有冇疲勞／親密度要求。

避免兩份系統文件互相 hard-code。

## 16. 實作規則

- 所有 recipe、resource node、drop table、tool bonus、quality multiplier 做成 data-driven。
- 禁止喺 UI component 內 hard-code 某張 recipe 嘅材料。
- 採取技能計算應由一個共用 service 負責。
- 合成成功率／品質只可以由一個共用 production resolver 計算。
- UI 顯示嘅成功率必須同實際 resolver 完全一致。
- 批量製作必須逐件使用同一 resolver，禁止另寫簡化公式。
- 生產物品使用現有 inventory catalog／equipment catalog；唔建立第二套互不兼容 item system。
- 生產工作台位置同 collision／interaction 使用現有地圖互動系統。
- 不要因加入生產系統改壞戰鬥、DECK、任務或裝備流程。

## 17. 驗收基準

### 採取

至少測試：

- 冇工具不可採取。
- 有正確工具可採取。
- 技能等級不足不可採高階節點。
- 技能提高後鎖定時間縮短。
- 稀有掉落仍按 drop table。
- 資源枯竭及 respawn 正常。
- 玩家離開地圖後再回來狀態合理。

### Recipe

- 未學 recipe 不可製作。
- Recipe item 學習後永久記錄。
- 重複 recipe 不會再重複學習。
- 等級不足顯示鎖定。
- 材料不足按鈕 disabled。
- 所需生產精靈未解鎖時不可製作。

### 合成

- UI 成功率 = 實際 resolver 成功率。
- 成功正確扣材料及加物品。
- 失敗正確扣材料但不出成品。
- 失敗仍只給 25% EXP。
- protected quest material 失敗時不消失。
- 親密度只按規則增加。
- Lv up 正常。
- Lv.40 cap 正常。

### 品質

大量 deterministic seeded tests 驗證：

- 只有 quality-enabled item Roll 品質。
- `N / +1 / +2 / S` multiplier 正確。
- 高技能／親密度只提高機率，不直接保證 S。
- 品質不可新增原本不存在嘅 stat。

### UI／流程

- 生產頁任何地方可查看。
- 不在正確工作台時不可製作。
- 打開生產頁不會自動移動／傳送玩家。
- 手機及桌面均可操作。
- 批量製作可取消。
- 關閉 modal 行為符合全遊戲共用規則。

### Save regression

- 舊 save 可正常載入。
- 生產技能、recipe、精靈親密度可存檔／讀檔。
- 不影響原有 inventory、equipment、quest、battle save。
